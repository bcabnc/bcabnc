## About

I teach **Computer Applications** at **B.N. College, Patna University**, build production software as a **full-stack engineer**, and write about **agentic AI, generative AI and cybersecurity**. So far I have published **8 technical books** and **7 bilingual (English + Hindi) research articles**.

> नमस्ते! मैं अतुल साह हूँ। मेरी पूरी वेबसाइट अंग्रेज़ी और हिन्दी दोनों भाषाओं में उपलब्ध है: **[atulsah.in/hi](https://atulsah.in/hi/)**

- Building: enterprise portals, AI-assisted apps, browser-based developer tools
- Researching: AI agents, Model Context Protocol (MCP), small language models, multi-agent systems
- Writing: books on AI, ML, Java, prompt engineering and AI-driven cybersecurity
- Philosophy: pure web standards, zero framework overhead, fast and accessible by default

**The interactive version of this profile lives at [atulsah.in](https://atulsah.in/)**: particle network canvas, magnetic cursor, project modals, bilingual switcher.
